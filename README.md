# Grammar Engineering

A simple NLTK grammar designed to accept valid English sentences, and reject invalid ones.

## Features

- Number agreement
- Verb subcategorization

# Pre-Requisites

Setup a virtual enviroment by running:

```bash
python -m venv venv
source venv/bin/activate
```

Then install the requirements using pip:

```bash
pip install -r requirements.txt
```

# Running

To run the final grammar, run:

```bash
python parse.py
```

To run the older grammars, set the grammar file to the relevant grammar in `parse.py`.
